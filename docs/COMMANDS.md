# 点歌指令手册

在**任意频道**里直接发消息即可，不需要 @机器人、不需要前缀之外的任何东西。

---

## 一、点歌（最常用）

| 写法 | 说明 |
|---|---|
| `!play 稻香` | 按歌名搜 |
| `!play 周杰伦 稻香` | 多个词会自动合并成搜索词 |
| `!dian 稻香` / `!bo 稻香` / `!gequ 稻香` | **拼音简写**，少打字 |
| `!play BV1G88y6xEQV` | 直接给 B站视频号 |
| `!play https://b23.tv/xxxxx` | 直接粘链接（短链/长链都行） |

> 你给什么它就播什么：**歌名**走搜索、**BV 号 / 链接**走直链。
> 长歌（4 小时演唱会那种）也是**秒开** —— 边解析边推流，不等整个文件下完。

---

## 二、播放控制

| 指令 | 拼音简写 | 作用 |
|---|---|---|
| `!pause` | `!zan` / `!zt` / `!jixu` | 暂停 / 继续（切换）|
| `!stop` | `!ting` / `!tz` | 停止并清空队列 |
| `!next` | `!xia` | 下一首 |
| `!previous` | `!shang` | 上一首 |
| `!volume 50` | `!yin 50` | 音量（0~100）|
| `!seek 90` | `!tiao 90` | 跳到第 90 秒 |
| `!song` | `!now` | 看当前在放什么 |

---

## 三、队列与播放模式

| 指令 | 拼音简写 | 作用 |
|---|---|---|
| `!list show` | `!lb` | 看队列 |
| `!list queue` | `!dui` | 同上（另一种写法）|
| `!repeat one` | `!danqu` | 单曲循环 |
| `!repeat all` | `!quanbu` | 列表循环 |
| `!repeat off` | — | 关掉循环 |
| `!random on` | `!sui` | 随机播放 |
| `!random off` | `!shun` | 顺序播放 |
| `!clear` | — | 清空队列 |

---

## 四、其它

| 指令 | 作用 |
|---|---|
| `!bz` | 查看**全部**命令（`!help` 的简写）|
| `!help play` | 看某条命令的详细用法 |
| `!history last` | 最近放过什么 |
| `!alias list` | 查看当前所有自定义别名 |

## 五、自定义别名（不用改配置文件）

机器人跑起来之后，可以直接在频道里加别名，**立刻生效并自动写回配置**：

```
!alias add 你好 "!play 周杰伦 稻香"     ← 之后发 !你好 就等于点这首歌
!alias add kt  "!play 周杰伦"           ← 不传参的固定别名
!alias add 随机 "!play 周杰伦 (!param 0)"
!alias list                              ← 看现有别名
!alias remove 你好                       ← 删除
```

### ⚠️ 两个必须知道的规则（很多人在这里踩坑）

1. **别名值必须以 `!` 开头。**
   写成 `"play"` 的话，它会被当成一段普通文字而不是命令，别名会「点了没反应」。

2. **想转发用户输入的参数，必须写 `(!param 0)`。**
   `(!param 0)` 的含义是「把命令名之后**整段文字**原样交给目标命令」，所以：

   ```
   dian = "!play (!param 0)"     ← ✅  !dian 周杰伦 稻香  →  等价于 !play 周杰伦 稻香
   dian = "!play"                ← ❌  !dian 稻香 里的「稻香」被丢掉，结果是"续播"
   ```

3. **中文别名需要 P7 补丁（本包自带，已启用）。**
   上游的命名校验正则是 `^[a-z\d]+( [a-z\d]+)*$`，中文会被拒绝
   （日志里只有一行 `Command has an invalid invoke name: 点歌`，很容易看漏）。
   本包自带的机器人已经打了 **P7**，把这个正则放宽到「任意语言的字母」，
   所以下面的中文别名可以直接用。

   ⚠️ 但 TOML 的 key **必须加引号**：
   ```toml
   "点歌" = "!play (!param 0)"     ← ✅
   点歌   = "!play (!param 0)"     ← ❌ TOML 语法错误，整个配置都读不出来
   ```

   如果你换成**官方原版**机器人，把中文别名那几行注释掉即可（不影响其它功能）。
   补丁细节见 [`patch-kit/README-patch.md`](../patch-kit/README-patch.md)。

## 六、本包内置的别名一览

见 [`config/bot.toml`](../config/bot.toml) 的 `[commands.alias]` 段：

**拼音 / 英文：**

```
dian / dg / gequ / bo   → 点歌        zan / zt / jixu  → 暂停/继续
ting / tz               → 停止        xia              → 下一首
shang                   → 上一首      yin <n>          → 音量
tiao <n>                → 跳转秒数    now              → 当前曲目
lb / dui                → 队列        danqu            → 单曲循环
quanbu                  → 列表循环    sui / shun       → 随机 / 顺序
bz                      → 全部命令
```

**中文（本包默认启用，依赖 P7 补丁）：**

```
点歌 / 播放   → 点歌       暂停 / 继续  → 暂停切换
停止          → 停止       下一首       → 下一首
上一首        → 上一首     当前         → 当前曲目
队列          → 看队列     音量 <n>     → 音量
随机 / 顺序   → 播放模式   循环 / 单曲  → 循环模式
帮助          → 全部命令
```

想加自己的：直接编辑服务器上的 `/opt/ts3bot/bots/default/bot.toml`，
或者用上面的 `!alias add`（推荐，会自动写回）。

## 七、点歌搜索为什么有时候"不对"？

代理里的选源逻辑（P6）会做四层筛选，尽量给你**原版、高码率**的那一条：

1. 优先在 B站**音乐区**里搜；结果太少就自动回退到全站
2. 按「**原版 > 现场 > 翻唱/改编 > 纯器乐**」分档
   —— 你自己搜的那一类不降级（你要是就想听翻唱，那它不会给你换回原版）
3. 同档内探真实音频码率，探到「原版 + ≥160kbps」就收手（不浪费请求）
4. **时长锚点**：以候选时长的中位数估计"这首歌该多长"，用 `exp(-0.06·Δt)` 打分，
   整活版 / 裁剪版 / 拼接版自然被淘汰

另外还认 **tag**（演奏 / 翻弹 / COVER / 纯音频…）、认 **拼音**（`zhoujielun daoxiang`）。

> ⚠️ B站的搜索接口**不认拼音** —— 拼音匹配只能在「已经返回的候选」里排序，
> 不能凭空把歌找出来。所以中文输入效果最好；拼音适合做二次排序。

搜不到 / 选错了，就把具体的 BV 号或者链接发过来，最准。
